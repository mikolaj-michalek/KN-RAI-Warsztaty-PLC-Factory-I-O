# KN-RAI-Warsztaty-PLC-Factory-I-O
Repozytorium warsztatów w ramach działalności Koła Naukowego Robotyka Automatyka Informatyka (RAI) na Politechnice Poznańskiej. Szkolenie przeznaczone dla osób początkujących, obejmuje konfigurację sterownika PLC, połączenie PLC SIM wraz z Factory I/O oraz implementację kodu do sortowania elementów na taśmie produkcyjnej.
